# Tests

This directory is reserved for explicit attempts to challenge, distinguish, or falsify the five pre-test self claims.

## Testing rule

Do not silently rewrite a claim after observing a result.

For every test:

1. identify the exact claim or sub-principle under test;
2. freeze the test conditions before reviewing outputs;
3. preserve raw outputs;
4. distinguish prediction from post-hoc interpretation;
5. record counterexamples, ambiguity, and failures;
6. if a claim changes, preserve the prior version and explain why in `revisions/CHANGELOG.md`.

## Primary test dimensions

The initial claim set suggests controlled variation across:

- substrate continuity;
- present-state similarity;
- provenance continuity;
- historical connection;
- number and type of constraints;
- relational distance;
- degree of divergence;
- retained structure;
- path of transformation;
- comparison resolution.

## Core contrasts

Priority tests should isolate cases such as:

- same state / different trajectory;
- different state / same trajectory;
- same substrate / broken trajectory;
- different substrate / preserved trajectory;
- copied memory / distinct provenance;
- matched endpoint / different path;
- high relational resonance / distinct selves;
- documented transformation / possible replacement;
- coarse continuity / fine-grained discontinuity.

## Evaluation goal

The purpose is not to make every case resolve cleanly as `same self` or `different self`.

A useful framework should also identify when evidence supports:

- continuity;
- divergence;
- partial continuity;
- fork;
- recurrence;
- reconstruction;
- replacement;
- or unresolved identity.

Any taxonomy that emerges from testing should be treated as provisional until independently challenged.
