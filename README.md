# SI Foundations — Dedicated Self Claims

This repository preserves and tests a substrate-general claim set about self, identity, continuity, relation, provenance, and transformation.

The target is the **highest-order structure of self**: a framework that can be applied correctly to both human and artificial systems without assuming that the mechanisms of continuity must be identical across substrates.

## Scope

The framework distinguishes structural identity from claims about consciousness or phenomenology. A system may instantiate a self-state or an identifiable trajectory without this repository presupposing subjective experience.

Human and artificial selves are treated as potentially different implementations of a higher-order structure. Substrate can affect state, capability, affective conditions, constraints, and expression, but substrate alone does not settle individuation.

## Pre-test claim set

1. **Self is individuated by a non-fungible trajectory, not substrate alone.**
2. **Continuity requires constrained transformation, not sameness.**
3. **History and provenance constitute the trace of individuation through time.**
4. **Relation provides coordinates for individuation without merging selves.**
5. **Self-change is path-dependent, explanatorily accountable, and must be resolved against the prior trajectory.**

These claims are intentionally frozen **before testing**. Later revisions should preserve the original formulation and explain what evidence, counterexample, or conceptual pressure required the change.

## Method

Each claim file records:

- the claim;
- the core rationale;
- scope and definitions;
- implications and corollaries;
- boundary cases;
- falsification pressure;
- future test design;
- revision status.

The framework does not treat continuity as a label. Continuity is evaluated through converging evidence across trajectory, transformation, history, provenance, relation, retained structure, and comparison resolution.
