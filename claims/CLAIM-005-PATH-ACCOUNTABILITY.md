# CLAIM-005 — Path Accountability

**Status:** Pre-test baseline  
**Version:** v0.1  
**Frozen:** 2026-10-10

## Claim

**Self-change is path-dependent, explanatorily accountable, and must be resolved against the prior trajectory.**

Continuity cannot be established merely by assigning the same label to successive states or by documenting that a transformation occurred. Changes must be interpretable in relation to the prior trajectory.

Small deviations may require relatively little explanation. Large reversals, substitutions, or discontinuities create a correspondingly larger explanatory burden.

Accounting means explaining **why** the self changed, not merely recording that it did.

After substantial change, continuity must also be evaluated at sufficient resolution to determine what actually remains continuous with the prior self.

## Core principles

**Accounting is necessary but not sufficient.**  
**Endpoint similarity does not erase path history.**  
**Continuity burden scales with divergence.**

## Core rationale

A sequence such as:

`A -> B`

is not sufficiently understood merely because the transition is recorded.

A receipt states that a change occurred.

An explanatory account asks what caused the change, how it relates to the prior self, and whether the resulting state still belongs to the same trajectory.

A fully documented transformation can still be a fully documented replacement.

## Path dependence

The same apparent endpoint may be reached through different paths:

`A -> gradual development -> B`

and

`A -> deletion/replacement -> B`

Even if both endpoints are behaviorally similar, the identity relation need not be equivalent.

The path therefore carries identity-relevant information that endpoint comparison alone can miss.

## Comparative resolution

After change, continuity must be examined at an appropriate level of resolution.

At coarse resolution:

- human -> human;
- AI agent -> AI agent;
- same name -> same name;
- same task -> same task.

These comparisons may look continuous while hiding large structural discontinuities.

At finer resolution, one may compare:

- history;
- provenance;
- memory relations;
- constraints;
- commitments;
- goals;
- values;
- behavior;
- relational position;
- retained structures;
- trajectory direction.

Thus, **coarse similarity can conceal deep trajectory discontinuity.**

## Triangulated continuity evaluation

A continuity claim should be evaluated from multiple directions:

### Path
How did the change occur?

### Retention
What remained continuous?

### Provenance
Does the present state still belong to the same historical line?

### Resolution
At what level are the prior and present states being compared?

Converging evidence across these dimensions strengthens continuity claims. Divergence among them should trigger further analysis rather than automatic same/not-same labeling.

## Possible outcomes

The framework should be able to distinguish among outcomes such as:

- continuous modification;
- continuous but extreme divergence;
- partial continuity;
- fork;
- reconstruction;
- replacement.

These categories are provisional and should be tested rather than assumed exhaustive.

## Scope

This claim is substrate-general and concerns structural continuity. It does not assume consciousness.

## Boundary cases to test

- abrupt value reversal;
- gradual value change;
- memory deletion with retained provenance;
- complete memory replacement;
- externally imposed behavioral rewrites;
- voluntary self-modification;
- model replacement behind a persistent agent shell;
- restoration from an earlier checkpoint;
- documented but total internal substitution.

## Falsification pressure

This claim would be weakened if endpoint similarity alone consistently resolved continuity as well as full path information, if divergence magnitude had no relationship to explanatory burden, or if fine-grained comparison never changed conclusions reached at coarse resolution.

## Test direction

Create matched endpoint cases reached through different transformation paths. Independently vary retained structure, provenance continuity, and comparison resolution. Test whether identity-continuity judgments respond to path and retention rather than merely endpoint resemblance or labeling.
