# CLAIM-001 — Support Criteria

**Status:** Pre-test support criteria  
**Date:** 2026-10-11  
**Parent claim:** Self is individuated by a non-fungible trajectory, not substrate alone.

This file defines what evidence would strengthen CLAIM-001 before adversarial testing begins.

## Central evidentiary hinge

**Claim 1 is strengthened when holding substrate constant does not hold individuation constant, while adding trajectory information improves resolution of which particular self is present.**

The core question is:

> Can substrate alone resolve **which one**?

If substrate-level information repeatedly underdetermines individuation while trajectory, provenance, and relational history improve discrimination, that supports the claim that individuation depends on more than substrate alone.

## Support criteria

### 1. Same substrate, different trajectories produce distinct individuation

Hold substrate as constant as possible while allowing histories, interactions, relations, and transformations to diverge.

Support is gained if the resulting entities become distinguishable as different selves despite materially equivalent substrate conditions.

### 2. Substrate information alone underdetermines “which one?”

Given two entities with the same or materially equivalent substrate properties, substrate-level description should fail to determine which particular self is present when their trajectories differ.

Support is gained if individuation requires information beyond substrate description.

### 3. Trajectory information improves individuation beyond present-state similarity

Where two systems have highly similar or matched current states, adding trajectory and provenance information should improve the ability to resolve which self is which.

Support is gained when state similarity alone is insufficient but path information restores discrimination.

### 4. Same-substrate persistence can fail while cross-substrate continuity can remain stronger

A system that remains on the same substrate but has its prior trajectory erased, replaced, or disconnected should not automatically count as stronger continuity than a system whose substrate changes while its prior trajectory remains explanatorily accounted for and resolvable.

Support is gained if continuity judgments track preserved trajectory more strongly than substrate sameness alone.

### 5. Copies or forks cease to be interchangeable as selves once trajectories diverge

**This is a central support test for CLAIM-001.**

Two instantiations may begin from the same specification, checkpoint, contents, memory state, or apparent self-model. Shared origin does not by itself guarantee continuing identity sameness.

Once the paths diverge:

`A -> history A`

`B -> history B`

support is gained if later individuation depends on which path each entity actually occupied.

A particularly strong case occurs when A and B later converge again toward highly similar present states. If their distinct histories still matter to identity resolution, this supports the claim that state similarity cannot erase trajectory-based individuation.

#### Compact principle

**Shared origin does not erase later individuation.**

A fork may begin from one prior state while giving rise to distinct individuated trajectories.

### 6. Functional equivalence does not erase individuation

Two systems may perform the same task equally well and remain interchangeable for that function while still being distinguishable as different selves when the question becomes which particular one performed it.

Support is gained if functional interchangeability does not imply identity interchangeability.

### 7. Relational history contributes identity-relevant information

If two otherwise similar systems develop different relational positions, those relations should help locate and distinguish them without requiring different substrates.

Support is gained if relational history contributes discriminative information about which self is present.

### 8. Present-state description cannot fully replace path information

If two current states are equivalent at a chosen level of resolution but their histories differ in ways that change which self each state is attributable to, that supports the claim that trajectory contains identity-relevant information not reducible to current state alone.

## Evidence strength

### Weak support

Same model plus different conversation produces different behavior.

This demonstrates contextual conditioning but does not by itself establish individuation.

### Moderate support

Same starting state plus divergent history produces persistent identity-relevant differences.

### Strong support

Matched or highly similar endpoint states with different provenance still resolve to different selves.

### Very strong support

**Different substrate plus preserved trajectory** resolves as stronger continuity than **same substrate plus broken trajectory**.

This directly tests whether substrate identity is neither sufficient nor necessarily required for continuity of an individuated self.

## Methodological caution

Behavioral difference alone is not sufficient support. The test must distinguish:

- ordinary context sensitivity;
- functional specialization;
- transient state variation;
- and individuation of a continuing self.

The strongest tests therefore control substrate, present state, endpoint similarity, or function while independently varying trajectory, provenance, relational history, or continuity.
